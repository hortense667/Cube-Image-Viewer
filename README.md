# 90 Days Cube

最大6枚の画像を立方体の各面へ貼り、展開図で並べ替え・編集し、ルービックキューブ風の解くデモを実行できる単一HTMLアプリです。画像処理は端末内だけで行います。

英語ドキュメント: `README.en.md`

## 言語モード（`lang` オプション）

- 既定は日本語表示です
- 英語表示にする場合は `?lang=en` を付けて開きます（例: `index.html?lang=en`）
- `?lang=en` は共有ビューURLと、ビューア右上の「90 Days Cube を開く →」で作成モードへ戻るリンクにも引き継がれます

## 使い方

1. `index.html` をブラウザで開く
2. 画像を1枚ずつ、またはまとめて選択する（最大6枚）
3. 展開図で配置を確認し、必要なら入れ替え・編集する
4. 「再生」でデモを見る。必要に応じて「立方体PNG保存」「展開図PNG保存」「① ランダム展開図をコピー」「② Xに投稿（URL付き）」を使う

## 画像の配置

- 1枚ずつ追加でき、空き面へ選択順に入ります（上・左・前・右・後・下）
- まとめて選ぶこともできます（最大6枚）。6枚以上指定した場合は先頭6枚のみ設定します
- 6枚揃うと追加選択はできません
- 設定済みの画像は、各面をタップして編集画面から差し替えできます
- 縦長・横長・高解像度の画像にも対応（面に合わせて位置・拡大・回転を調整）

## 展開図の操作

- ドラッグで面を入れ替え
- タップで編集画面を開く（移動・拡大縮小・90度回転・画像差し替え）

## キューブを解くデモ

- ランダムに崩したあと逆手順で解き、少し静止して再び始めます
- 「停止」でルービック状態を初期状態へ戻します
- 速度スライダーで再生速度を調整できます
- ドラッグで向きを変え、ピンチ／ホイールで拡大縮小できます

### 視点演出

| 項目 | 内容 |
| --- | --- |
| 回転 | ヨコ方向にゆっくり自動回転（初期オン） |
| 向き変化 | ときどき向きを変え、回転方向も切り替えます |

## 書き出し

- 立方体PNG保存
- 展開図PNG保存
- 全画面表示

## 共有（X投稿フロー）

このアプリの公開向け共有は、展開図画像を投稿に添付し、本文の `Viewer:` 行にURLを入れる方式です。

### PCで共有する場合

1. 画像を6枚設定する
2. 「① ランダム展開図をコピー」を押す
3. 「② Xに投稿（URL付き）」を押す
4. 投稿画面で、先ほどコピーした画像を貼り付けて投稿する

### スマホで共有する場合

1. 画像を6枚設定する
2. 「① 共有テキストをコピー」を押す
3. 「② X投稿用に画像を共有」を押してX投稿画面を開く
4. 投稿画面で画像を添付し、本文へ先ほどコピーした共有テキストを貼り付けて投稿する

受け取った側は、投稿本文の `Viewer:` URL を開いたあと、「クリップボードから読み取り」で画像を読み込むと再生できます。

### 共有時の注意

- `file://` のローカルURLは相手の環境で開けないため、`https` で公開したURLを使ってください
- 他人の写真や、プライベートな内容を含む画像の共有は避けてください
- 共有される画像は閲覧向けの展開図であり、元画像そのものではありません
- スマホ共有の投稿を **PCで閲覧** するときは、X上の添付画像を一度拡大表示してからコピーして貼り付けると、より綺麗に表示されます
- ブラウザ制限により、リンクを開いた瞬間の自動全画面はできません（最初の操作で全画面に入ります）
